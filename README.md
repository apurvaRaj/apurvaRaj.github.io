# apurvaraj.github.io

Personal site of Apurva Raj: an immersive portfolio, project case studies, a knowledge hub and a learning log. Live at **https://apurvaraj.github.io**.

## Stack

| Layer | Choice | Why |
|---|---|---|
| Site | [Astro](https://astro.build) 7, static output | Every page is real HTML at build time: fast, crawlable, works on GitHub Pages with direct links and refresh |
| 3D | three.js (vanilla, no React) | One particle field on the home page; loaded only there |
| Motion | GSAP + ScrollTrigger, Lenis | Scroll choreography and smooth scrolling on one clock |
| Content | Markdown with typed frontmatter | Add a project or article by adding a file |
| Fonts | Archivo, Newsreader (self-hosted via Fontsource) | No third-party font requests |
| Deploy | GitHub Actions → GitHub Pages | Builds and publishes on every push to `main` |

## Run it locally

```bash
npm ci
npm run dev       # http://localhost:4321
npm run build     # outputs dist/
npm run preview   # serves dist/
```

Node 22 or newer.

## Deployment

1. In the repository, open **Settings → Pages** and set **Source** to **GitHub Actions** (one time).
2. Push to `main`. The workflow in `.github/workflows/deploy.yml` builds, checks the output and publishes.

### Custom domain

1. Add the domain under **Settings → Pages → Custom domain** and create the DNS records GitHub shows.
2. Add a repository variable `SITE_URL` (for example `https://apurvaraj.com`) so canonical URLs, the sitemap and RSS use it.
3. Tick **Enforce HTTPS** once the certificate is issued.

### Analytics and search consoles (all optional)

Add these as repository **variables** (Settings → Secrets and variables → Actions → Variables). Nothing is loaded until they are set.

| Variable | Value |
|---|---|
| `PUBLIC_GA4_ID` | Google Analytics 4 measurement ID, `G-XXXXXXX` |
| `PUBLIC_GOOGLE_SITE_VERIFICATION` | The `content` value of Search Console's HTML-tag method |
| `PUBLIC_BING_SITE_VERIFICATION` | The `content` value of Bing Webmaster Tools' meta-tag method |

Then submit `https://apurvaraj.github.io/sitemap-index.xml` in both consoles.
